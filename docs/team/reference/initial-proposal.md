# 한국농산 협력업체 통합관리 및 만료 알림 PoC 기획서

- 작성자: JinsuBae2
- 최종 수정일: 2026-09-22
- 상태: 초안

## 1. 문서 목적

한국농산과의 첫 미팅 전 프로젝트의 문제 인식, 목표, 예상 범위와 검증 방법을 제안한다. 현업 인터뷰와 실제 자료 분석 전이므로 세부 기능과 업무 규칙은 미팅 후 확정한다.

## 2. 추진 배경

현재 파악된 문제는 협력업체 관련 계약, 인증, 발주와 납기자료가 여러 파일과 관리 경로에 분산되어 있다는 점이다. 자료 조회에 시간이 들고 계약·인증 만료를 놓칠 위험이 있으며, 담당자 변경 시 업무 인수인계가 어렵다.

이번 프로젝트는 협력업체 정보를 한곳에서 관리하고 계약·인증 만료 대상을 자동으로 식별하는 PoC를 구축해 업무 적용 가능성을 검증한다. 기업 요구와 일정이 허용되면 제한된 사용자 대상 MVP 수준으로 확장한다.

## 3. 프로젝트 목표

1. 협력업체 기본정보와 관련 자료를 업체 단위로 통합한다.
2. 계약과 인증의 유효기간 및 갱신상태를 일관되게 관리한다.
3. 만료 예정 항목을 사전에 식별하고 담당자에게 알린다.
4. 발주·납기 현황의 통합 조회 필요성을 확인한다.
5. 실제 담당자의 평가로 서비스 전환 가능성을 검증한다.

## 4. PoC와 MVP 경계

### 1차 PoC 필수 범위

- 협력업체 등록·조회·수정·검색
- 업체별 계약과 인증 등록·조회
- 계약·인증 만료상태 자동 계산
- 만료 90일·30일·7일 전 대상 추출
- 만료 예정 대시보드와 필터
- 비식별 샘플 데이터 기반 검증

### 일정과 기업 요구 확인 후 확장

- 로그인과 역할별 권한
- 실제 파일 업로드·다운로드
- 이메일 등 실제 알림 발송
- 엑셀 일괄 등록
- 갱신 처리 및 변경 이력
- 발주·납기 조회
- 운영 환경 배포

### 1차 PoC 제외 권장 범위

- ERP 실시간 연동
- 전자계약과 전자결재
- 문자·외부 메신저 알림
- 협력업체 외부 포털
- 자동 평가 및 등급 산정

## 5. 예상 사용자

|---|---|---|
| 시스템 관리자 | 사용자, 권한, 기준정보 관리 | 실제 관리자 부서와 인원 |
| 협력업체 담당자 | 업체정보와 계약·인증 관리 | 등록·수정 책임자 |
| 구매·발주 담당자 | 발주·납기 현황 확인 | 기존 시스템과 업무절차 |
| 조회 사용자 | 대시보드와 현황 조회 | 조회범위와 권한 차이 |

## 7. 핵심 업무 흐름

1. 담당자가 협력업체 기본정보를 등록한다.
2. 업체와 연결된 계약 또는 인증의 유효기간을 등록한다.
3. 시스템이 현재일과 만료일을 비교해 상태를 계산한다.
4. 기준일에 도달한 항목을 대시보드와 만료 목록에 표시한다.
5. 담당자가 갱신 진행상태를 기록하고 새 자료를 등록한다.
6. 관리자가 미처리 대상과 전체 현황을 확인한다.

### 핵심 테스트

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| VT-001 | 협력업체 정상 등록 | 목록과 상세에 동일한 정보 표시 |

### 성공 기준 초안

- 샘플 데이터 기준 만료 판정 정확도 100%
- Must 시나리오 수행 성공률 90% 이상
- 동일 대상·기준의 중복 알림 0건
- 업체와 계약·인증 연결 오류 0건
- 실제 담당자 사용성 평가 5점 중 4점 이상

정량 목표는 기업의 현재 기준과 데이터 규모를 확인한 뒤 확정한다.
