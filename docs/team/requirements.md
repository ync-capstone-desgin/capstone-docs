# 요구사항 정의서

- 작성: 404팀 (배진수, 박준영, 조대성)
- 최종 수정일: 2026-10-21
- 상태: 초안 (M1 요구사항 확정 단계, 10/23 확정 목표)
- 근거: [10/20 미팅 회의록](meetings/2026-10-20-meeting.md), [초기 기획서](reference/initial-proposal.md) 6·9장, 프로토타입 `v0.1-demo`

## 1. 문서 목적

한국농산 협력업체 통합관리 시스템이 **무엇을 해야 하는지**를 한곳에 정리한다.
요구사항마다 번호(ID)를 붙여 이슈·PR·테스트가 이 번호를 참조하게 하고, 최종 발표 때 "요구사항 → 구현 → 검증"을 추적하는 기준으로 쓴다.

## 2. 배경과 목표

### 2.1 현재 문제 (10/20 미팅 확인)

- 협력업체 계약·인증 자료를 **엑셀과 파일을 뒤져서** 찾는다.
- 계약·인증 **만료를 놓친 적이 있다.**
- 협력업체는 현재 **10곳**이며, 계약이 생길 때마다 늘어난다.
- **여러 직원**이 함께 쓸 예정이고, 시연용이 아니라 **실제 업무에 쓸 가능성이 높다.**

### 2.2 목표

1. 협력업체별 계약·인증과 관련 자료(파일)를 한곳에 모은다.
2. 만료 예정 건을 자동으로 찾아 담당자에게 **메일로** 미리 알린다.
3. 사내 공용 양식 문서를 공유한다.
4. PC와 **휴대폰** 어디서든 확인할 수 있다.
5. 여러 직원이 각자 계정으로 안전하게 쓴다.

## 3. 사용자

| 사용자 | 하는 일 | 비고 |
|---|---|---|
| 관리자 (ADMIN) | 사용자 가입 승인·역할 지정, 알림 기준 설정, 모든 업무 | 한국농산 내 관리 책임자 (누구인지 확인 필요) |
| 담당자 (MANAGER) | 업체·계약·인증·자료 등록·수정, 갱신 처리, 알림 처리 | 여러 직원 |
| 조회자 (VIEWER) | 조회·다운로드만 | 필요 여부 확인 필요 |

- 직원마다 볼 수 있는 업체 범위를 나눌지(예: 내 담당 업체만)는 **미정**이다. 지금은 모든 직원이 전체를 보고, "내 담당만" 필터로 좁혀 보는 방식이다.

## 4. 기능 요구사항

- **우선순위**: `Must` 꼭 필요 / `Should` 있으면 좋음 / `Could` 여유 있으면 / `Won't` 이번 범위 아님
- **상태**: `완료` 프로토타입(v0.1-demo)에 구현 / `예정` 개발 예정 / `보류` 다시 넣을 예정 / `확인 필요` 기업 확인 후 확정
- **마일스톤**: M2-1 핵심 기능(10/26~11/13), M2-2 확장·반응형(11/16~12/4)

## 8. 성공 기준 (최종 시연)

- 샘플 데이터 기준 만료 판정 정확도 100%, 중복 알림 0건
- Must 요구사항 전부 구현, 시나리오 수행 성공률 90% 이상
- 실제 직원이 휴대폰과 PC에서 주요 업무 수행 성공
- 담당자 사용성 평가 5점 중 4점 이상
