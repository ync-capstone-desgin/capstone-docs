# 한국농산 협력업체 통합관리 & 계약·인증 만료 알림 PoC — 개인 기획안 (초안)

## 1. 문제 정의

한국농산은 협력업체 관련 데이터(계약, 인증, 발주, 납기)가 구매팀·품질팀·영업팀 등 부서별로 흩어져 있어 통합 관리가 되지 않고 있다고 밝힘. 이로 인해 다음과 같은 문제가 발생할 수 있다고 추정됨(**미팅 확인 필요**):

- 인증 만료를 놓쳐 거래정지·과태료 등 리스크 발생 가능성
- 계약 갱신 시점을 놓치는 사례
- 발주·납기 현황을 한눈에 파악하기 어려움

> 실제 문제 발생 빈도, 과거 사고 사례 여부는 기업 미팅에서 확인 필요.

## 2. 목표

- 협력업체 관련 데이터를 하나의 시스템에서 통합 조회할 수 있게 한다.
- 계약·인증 만료가 임박하면 자동으로 알림을 받을 수 있게 한다.
- 3인 팀이 1개월 내에 완성 가능한 PoC(Proof of Concept) 수준으로 범위를 제한한다.

## 3. 기능 및 PoC 범위 (제안, 팀 논의 필요)

### 포함 (이번 PoC)
- 협력업체 마스터 등록·조회 (계약/인증/발주/납기 통합 뷰)
- 계약·인증 만료일 자동 판정 (제안 기준: D-30 / D-14 / D-7 — **실제 기준은 미팅 확인 필요**)
- 대시보드 알림 + 이메일 알림 발송
- 통합 검색·필터 (업체명, 인증유형, 만료 임박 여부)

### 제외 (향후 확장, 이번 PoC 범위 아님)
- 발주 자동화 워크플로, 전자결재
- 사내 ERP·그룹웨어 실시간 연동
- 카카오톡·문자 알림, 모바일 앱
- 협력업체 자가 포털, 역할기반 권한 세분화

> 위 범위는 개인 제안이며, 팀 회의 및 기업 미팅 결과에 따라 조정될 수 있음.

## 4. 기업 미팅 확인 질문 (questionnaire 겸용)

### 협력업체 기본 현황
- 협력업체 수는 대략 몇 개인가?
- 협력업체를 관리하는 부서가 몇 개이고, 각각 어떤 데이터를 갖고 있나?

### 계약 관련
- 계약서는 어떤 형태로 존재하나? (종이/한글·워드 파일/엑셀 목록)
- 계약기간·자동갱신 여부·계약금액이 실제로 관리되고 있나?
- 계약 갱신은 현재 누가 언제 챙기나?

### 인증 관련
- 어떤 인증을 관리하나? (HACCP, GAP, 유기농인증 등 실제 종류 — 예시일 뿐 확인 필요)
- 인증서 유효기간이 인증마다 다른가?
- 인증서 파일을 어디에 보관하고 있나?

### 발주·납기 관련
- 발주는 지금 어떤 방식으로 처리되나?
- "납기 지연" 기준이 있나? (예정일 대비 며칠 초과부터인지)
- 발주·납기 데이터가 계약/인증과 연결되어 관리되나, 완전히 별개인가?

### 알림 요구사항
- 만료 임박 알림은 며칠 전부터 받고 싶은가? (D-30/14/7 적절한지)
- 알림을 누가 받아야 하나? (담당자 개인 / 부서 공용 메일 / 팀장 등)
- 이메일로 충분한가, 문자·카카오톡도 필요한가?

### 시스템 환경
- 현재 사용 중인 ERP·그룹웨어가 있나? 향후 연동이 필요한가?
- PoC 접근 환경은? (사내망만 / 외부 접속 필요 여부)

### 보안/권한
- 계약금액 등 민감정보에 접근 제한이 필요한가?
- 로그인/계정 체계가 PoC 단계에서도 필요한가?

### 데이터 실물 확인 (중요)
- 실제 계약대장/발주 엑셀/인증서 목록 **샘플 파일**을 받을 수 있는가?
- 업체코드, 품목코드 같은 고유 식별 체계가 이미 있는가, 업체명만 텍스트로 관리되는가?

### 과거 이력 / 실패 경험
- 예전에 비슷한 시스템을 시도했다가 실패한 적이 있는가? 있다면 이유는?

### 사용자·조직 범위
- 실제 사용자는 몇 명, 어느 부서인가?
- 협력업체 쪽에서 직접 접근(업로드/조회)할 필요가 있는가?
- 해외 협력업체·수입 농산물도 다루는가? (해외 인증 체계 포함 여부)

### 데이터 이관
- 기존 데이터를 PoC 시스템에 처음에 누가, 어떻게 입력할 것인가?

### 이력관리/책임소재
- 계약·인증 정보 수정 시 변경 이력 기록이 필요한가?
- 알림을 담당자가 방치하면 에스컬레이션(상위자 재알림)이 필요한가?

### 계절성/업무 패턴
- 성수기·비수기에 따라 발주량 변동이 큰가?

### 예산·인프라·보고 체계
- PoC 서버/인프라 지원이 있는가?
- 중간보고 일정이 필요한가?
- 미팅 참석자가 최종 요구사항 승인권자인가?
