# 한국농산 PoC 자료 요청 목록

## 1. 요청 원칙

실제 개인정보와 영업기밀을 최소화하고, 가능하면 비식별 또는 가공된 샘플을 요청한다. 자료 제공 전 한국농산의 보안정책과 저장 가능 위치를 확인한다.

## 2. 우선 요청 자료

| 우선순위 | 자료 | 확인 목적 | 권장 형태 |
|---|---|---|---|
| 필수 | 협력업체 관리대장 샘플 | 기본정보와 상태 항목 파악 | 비식별 엑셀 10~20건 |
| 필수 | 계약 관리대장 샘플 | 계약 항목과 기간 규칙 파악 | 비식별 엑셀 10건 내외 |
| 필수 | 인증 관리대장 샘플 | 인증 종류와 만료 규칙 파악 | 비식별 엑셀 10건 내외 |
| 필수 | 실제 업무 절차 설명 | 등록·갱신·확인 흐름 파악 | 설명 또는 업무 흐름도 |
| 권장 | 계약서 양식 | 문서에서 관리할 항목 파악 | 민감정보 제거 PDF |
| 권장 | 인증서 양식 | 인증번호와 유효기간 위치 파악 | 민감정보 제거 PDF |
| 협의 | 발주·납기자료 샘플 | 발주·납기 최소 범위 결정 | 비식별 엑셀 10~20건 |
| 협의 | 사용자·권한 구분표 | 역할별 접근범위 설계 | 부서·역할 중심 표 |

## 3. 받지 않아야 할 정보

- 실명, 개인 연락처 등 불필요한 개인정보
- 계좌번호, 주민등록번호, 비밀번호
- 실제 시스템 계정과 API 키
- 공개 또는 반출이 금지된 계약 원문
- 개발 범위와 관계없는 대량의 운영 데이터

## 4. 자료 수령 시 기록사항

- 자료명과 제공일
- 제공 담당자
- 사용 목적
- 민감정보 포함 여부
- 보관 위치와 접근 가능 인원
- 반환 또는 삭제 시점
- PoC 종료 후 처리 방법
