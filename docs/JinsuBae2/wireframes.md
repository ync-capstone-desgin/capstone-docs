# 협력업체 통합관리 PoC 텍스트 와이어프레임

- 작성자: JinsuBae2
- 최종 수정일: 2026-09-22
- 상태: 초안

실제 디자인이 아니라 화면별 정보 구조와 사용자 흐름을 검토하기 위한 텍스트 초안이다.

## 1. 대시보드

```text
+----------------------------------------------------------+
| 협력업체 통합관리                         사용자 메뉴     |
+----------------------------------------------------------+
| 전체 업체 | 활성 계약 | 만료예정 인증 | 만료 항목         |
|    00     |    00     |      00       |    00             |
+----------------------------------------------------------+
| 만료 임박 목록                                            |
| 유형 | 업체 | 계약·인증명 | 만료일 | D-day | 담당자 | 상태 |
+----------------------------------------------------------+
| 최근 알림 및 처리현황                                     |
+----------------------------------------------------------+
```

확인사항: 대시보드에서 가장 먼저 봐야 하는 지표, 담당자별 보기 필요 여부.

## 2. 협력업체 목록

```text
+----------------------------------------------------------+
| 협력업체 관리                              업체 등록      |
+----------------------------------------------------------+
| 검색어 [              ] 상태 [전체 v] 인증 [전체 v] 검색 |
+----------------------------------------------------------+
| 업체명 | 사업자번호 | 담당자 | 계약 | 인증 | 만료 | 상태 |
| ...                                                      |
+----------------------------------------------------------+
```

확인사항: 필수 검색 조건, 목록에 노출할 개인정보, 업체 상태 종류.

## 3. 협력업체 상세

```text
+----------------------------------------------------------+
| 업체명                                      수정          |
| 기본정보 요약                                             |
+----------------------------------------------------------+
| [계약] [인증] [발주·납기 선택] [변경이력 선택]             |
+----------------------------------------------------------+
| 선택한 탭의 목록                            신규 등록      |
| 명칭 | 번호 | 시작일 | 만료일 | 상태 | 담당자 | 파일      |
+----------------------------------------------------------+
```

확인사항: 하나의 업체를 여러 부서가 관리하는지, 탭 구성이 실제 흐름과 맞는지.

## 4. 계약·인증 등록

```text
+----------------------------------------------------------+
| 계약 또는 인증 등록                                      |
+----------------------------------------------------------+
| 업체              [선택]                                 |
| 유형              [선택]                                 |
| 명칭·번호         [입력]                                 |
| 시작일·발급일     [날짜]                                 |
| 종료일·만료일     [날짜]                                 |
| 담당자            [선택]                                 |
| 파일 또는 링크    [선택]                                 |
| 상태              [자동 또는 선택]                       |
+----------------------------------------------------------+
| 취소                                           저장       |
+----------------------------------------------------------+
```

확인사항: 계약과 인증을 하나의 입력 흐름으로 둘지 분리할지, 필수 항목.

## 5. 만료 예정 목록

```text
+----------------------------------------------------------+
| 만료 및 갱신 관리                                        |
+----------------------------------------------------------+
| 기간 [30일 v] 유형 [전체 v] 담당자 [전체 v] 상태 [전체 v]|
+----------------------------------------------------------+
| D-day | 유형 | 업체 | 대상명 | 만료일 | 담당자 | 처리상태 |
| D-7   | 인증 | ...  | ...    | ...    | ...    | 진행중   |
+----------------------------------------------------------+
| 선택 항목 상태 변경 | 담당자 지정 | 내보내기 선택          |
+----------------------------------------------------------+
```

확인사항: 알림과 업무 처리상태를 같은 화면에서 관리할지, 일괄처리 필요 여부.

## 6. 화면 간 이동

```text
대시보드
  |-- 만료 건 선택 ------> 만료 예정 목록 ------> 업체 상세
  |-- 업체 수 선택 ------> 협력업체 목록 --------> 업체 상세
  |                                              |-- 계약 등록
  |                                              `-- 인증 등록
  `-- 최근 알림 선택 ----> 만료 예정 목록
```
