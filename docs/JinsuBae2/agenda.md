# 한국농산 첫 미팅 진행안

## 1. 권장 시간

총 60분을 기준으로 진행한다.

| 시간 | 내용 | 진행 주체 | 목표 |
|---|---|---|---|
| 0~5분 | 참석자 소개와 미팅 목적 | 프로젝트팀 | 오늘 결정할 항목 공유 |
| 5~20분 | 현행 업무와 문제 설명 | 한국농산 | 실제 업무 흐름과 어려움 이해 |
| 20~35분 | 계약·인증·발주·납기 상세 질문 | 공동 | 데이터와 규칙 확인 |
| 35~45분 | PoC 범위 초안 제안 | 프로젝트팀 | 필수·제외 범위 의견 수렴 |
| 45~53분 | 일정, 자료, 보안 조건 협의 | 공동 | 협업 방식과 제약 확인 |
| 53~60분 | 결정사항과 후속 조치 정리 | 프로젝트팀 | 담당자와 기한 확정 |

## 2. 프로젝트팀 준비물

- 사전 기획서
- 핵심 화면 4~5개의 간단한 와이어프레임
- 미팅 질문지
- 12주 일정표
- 자료 요청 목록
- 회의 결과 기록지

## 3. 역할 분담 예시

| 역할 | 담당 업무 |
|---|---|
| 진행자 | 시간 관리, 질문 순서 조정, 합의사항 재확인 |
| 질문 담당 | 업무·데이터·보안 질문 진행 |
| 기록 담당 | 답변, 결정사항, 미확정 사항 기록 |
| 기술 담당 | 구현 가능성, 연동, 일정 관련 답변 |

## 4. 진행 원칙

- 준비한 솔루션을 먼저 설명하기보다 현행 업무를 먼저 듣는다.
- 기능 요청의 배경과 실제 사용자를 함께 확인한다.
- 즉시 답하기 어려운 기술 내용은 추측하지 않고 확인 후 회신한다.
- 미팅 종료 전에 결정사항, 미확정 사항, 담당자와 기한을 읽어 확인한다.
