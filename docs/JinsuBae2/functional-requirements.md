| 우선순위 | 의미 |

## 4. 핵심 사용자 시나리오

### 시나리오 A 협력업체와 계약 등록

1. 사용자가 협력업체를 등록한다.
2. 업체 상세에서 계약을 추가한다.
3. 계약 종료일을 입력한다.
4. 시스템이 만료 상태를 계산한다.

### 시나리오 B 인증 만료 확인

1. 사용자가 인증 종류와 만료일을 등록한다.
2. 시스템이 알림 기준일을 계산한다.
3. 대시보드와 만료 목록에 해당 인증이 표시된다.
4. 사용자가 갱신 진행상태를 변경한다.

### 시나리오 C 관리자 현황 확인

1. 관리자가 대시보드에 접속한다.
2. 만료 임박 건수를 확인한다.
3. 업체 또는 담당자 기준으로 필터링한다.
4. 미처리 대상을 확인하고 담당자에게 후속 조치를 요청한다.
