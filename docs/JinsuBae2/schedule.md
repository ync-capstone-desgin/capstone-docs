## 1. 일정 원칙

12주 기준 초안이며 학사일정, 팀 인원, 기업 검토 가능일과 데이터 제공 시점에 따라 조정한다. 개발 시작 전에 문제, 데이터, PoC 범위와 성공 기준을 먼저 확정한다.

## 4. 변경 관리

- 새 요청은 필수, 중요, 후속검토로 구분한다.
- 필수범위 추가 시 일정 또는 기존범위 조정을 함께 결정한다.
- 데이터 제공이 지연되면 비식별 샘플로 개발하고 실제 데이터 검증일을 별도로 확보한다.
- 매주 완료 항목, 다음 작업, 위험과 필요한 협조사항을 기록한다.
