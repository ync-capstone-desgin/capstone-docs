# 한국농산 첫 미팅 질문지

## 1. 미팅 목표

첫 미팅에서는 해결하려는 문제, 실제 사용자, 데이터 위치, 만료 관리 방식, PoC 범위와 성공 기준을 확인한다. 모든 질문을 순서대로 묻기보다 담당자의 업무 설명을 먼저 듣고 필요한 항목을 보충한다.

## 2. 우선 확인 질문

### 업무와 문제

1. 협력업체 관련 업무는 어떤 부서와 담당자가 수행합니까?
2. 현재 가장 시간이 많이 들거나 누락 위험이 큰 업무는 무엇입니까?
3. 협력업체 한 곳을 등록한 뒤 계약, 인증, 발주, 납기를 관리하는 전체 절차는 어떻게 됩니까?
4. 최근 실제로 발생한 만료 누락, 자료 검색 지연 또는 납기 확인 문제 사례가 있습니까?
5. 이번 PoC가 해결해야 할 가장 중요한 문제 한 가지는 무엇입니까?

### 협력업체 정보

6. 현재 관리하는 협력업체 수와 월평균 신규·변경 건수는 어느 정도입니까?
7. 업체별로 반드시 관리해야 하는 기본정보는 무엇입니까?
8. 업체의 정상, 중지, 종료 등 상태 구분이 필요합니까?
9. 동일 업체를 여러 부서 또는 담당자가 함께 관리합니까?

### 계약과 인증

10. 관리 대상 계약의 종류와 평균 건수는 어느 정도입니까?
11. 관리 대상 인증에는 어떤 종류가 있습니까?
12. 계약과 인증마다 만료 또는 갱신 규칙이 다릅니까?
13. 갱신이 필요한 시점과 실제 갱신 절차는 어떻게 됩니까?
14. 현재 만료일과 갱신 여부는 어디에 기록합니까?
15. 과거 문서와 갱신 이력을 보존해야 합니까?

### 알림

16. 만료 며칠 전에 알림이 필요합니까?
17. 계약·인증 종류별로 알림 시점을 다르게 설정해야 합니까?
18. 알림을 받아야 하는 사람은 담당자, 관리자 또는 협력업체 중 누구입니까?
19. 원하는 알림 채널은 시스템 화면, 이메일, 문자 또는 메신저 중 무엇입니까?
20. 알림 확인, 갱신 진행, 완료 상태를 기록해야 합니까?
21. 미처리 상태일 때 반복 알림이나 상위 담당자 알림이 필요합니까?

### 발주와 납기

22. 발주와 납기자료는 현재 어떤 시스템 또는 파일에서 관리합니까?
23. PoC에서 필요한 것은 단순 조회입니까, 등록·수정까지 포함합니까?
24. 납기 지연은 어떤 기준으로 판단합니까?
25. 발주 건과 협력업체, 계약을 연결해야 합니까?
26. 기존 ERP 또는 다른 시스템과의 연동이 최종 서비스에 필요합니까?

### 데이터와 보안

27. 현재 자료 형식은 엑셀, 문서, PDF, 이메일 또는 시스템 중 무엇입니까?
28. 비식별 샘플 데이터를 제공할 수 있습니까?
29. 계약서와 인증서 원본을 시스템에 저장해도 됩니까?
30. 개인정보 또는 영업기밀에 해당하는 항목은 무엇입니까?
31. 외부 클라우드, 학교 서버 또는 개발팀 장비 사용에 제한이 있습니까?
32. 데이터 보관기간과 삭제 기준이 있습니까?

### 사용자와 권한

33. 예상 사용자 수와 동시 사용자는 어느 정도입니까?
34. 조회, 등록, 수정, 삭제 권한을 역할별로 구분해야 합니까?
35. 변경 이력과 누가 수정했는지 기록해야 합니까?
36. 협력업체가 직접 접속하는 기능이 필요합니까?

### 성공 기준과 운영

37. PoC가 성공했다고 판단할 수 있는 기준은 무엇입니까?
38. 시연 시 반드시 동작해야 하는 업무 시나리오는 무엇입니까?
39. 기업 담당자가 중간 결과를 검토할 수 있는 주기는 어느 정도입니까?
40. PoC 종료 후 실제 서비스로 전환할 때 가장 중요한 조건은 무엇입니까?

## 3. 미팅 종료 전 확인 체크리스트

- [ ] 핵심 문제와 우선순위
- [ ] 주요 사용자와 담당 부서
- [ ] 필수 기능과 제외 기능
- [ ] 관리 대상 계약·인증 종류
- [ ] 만료 및 알림 규칙
- [ ] 제공 가능한 샘플 자료와 제공일
- [ ] 보안과 저장 환경 제약
- [ ] 중간 검토 일정
- [ ] PoC 성공 기준
- [ ] 다음 미팅까지 양측의 할 일과 담당자
