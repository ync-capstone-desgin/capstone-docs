## 1. 미팅 목표

첫 미팅에서 실제 업무 문제, 사용자, 데이터, 만료 규칙, PoC 범위와 성공 기준을 확인한다. 준비한 솔루션을 먼저 설명하기보다 현행 업무와 최근 문제 사례를 먼저 듣는다.

## 2. 60분 진행안

| 시간    | 내용                     | 진행 주체  | 목표                     |
| ------- | ------------------------ | ---------- | ------------------------ |

| 5~20분  | 현행 업무와 문제 설명    | 한국농산   | 실제 흐름과 어려움 이해  |
| 20~35분 | 계약·인증·발주·납기 질문 | 공동       | 데이터와 규칙 확인       |
| 35~45분 | PoC 범위 초안 제안       | 프로젝트팀 | 필수·제외 범위 의견 수렴 |

## 3. 우선 질문

### 업무와 문제

1. 협력업체 업무는 어떤 부서와 담당자가 수행합니까?
2. 협력업체 관리 실무 담당자는 총 몇 명이며, 1인 전담입니까 아니면 다른 업무와 겸임·분담하고 있습니까?
3. 가장 시간이 많이 들거나 누락 위험이 큰 업무는 무엇입니까?
4. 업체 등록부터 계약·인증·발주·납기관리까지 전체 절차는 어떻게 됩니까?
5. 최근 만료 누락, 자료 검색 지연 또는 납기 확인 문제 사례가 있습니까?
6. 이번 PoC가 반드시 해결해야 할 문제 한 가지는 무엇입니까?

### 협력업체·계약·인증

7. 관리하는 협력업체 수와 월평균 변경 건수는 어느 정도입니까?
8. 업체별 필수 관리정보와 상태 구분은 무엇입니까?
9. 신규 계약이나 재계약은 어떤 방식(서면 날인, 전자계약 등)으로 진행하며, 체결된 계약서 원본과 계약 정보는 현재 어떻게 보관·관리(종이 바인더, 엑셀 대장, 사내 공유 드라이브 등)하고 있습니까?
10. 관리 대상 계약과 인증의 종류·평균 건수는 어느 정도입니까?
11. 계약·인증별 만료 또는 갱신 규칙이 다릅니까?
12. 만료일이 없거나 자동연장되는 계약·인증이 있습니까?
13. 갱신 절차와 책임자는 누구입니까?
14. 과거 문서와 갱신 이력을 보존해야 합니까?

### 알림

15. 만료 며칠 전에 알림이 필요합니까?
16. 종류별로 알림 시점을 다르게 설정해야 합니까?
17. 알림 수신자는 담당자, 관리자 또는 협력업체 중 누구입니까?
18. 원하는 채널은 화면, 이메일, 문자 또는 메신저 중 무엇입니까?
19. 확인·진행·완료 상태와 반복 알림이 필요합니까?

### 발주·납기와 연동

20. 발주·납기자료는 현재 어디에서 관리합니까?
21. PoC에는 조회만 필요합니까, 등록·수정도 필요합니까?
22. 납기 지연 기준과 부분 납품 처리는 어떻게 합니까?
23. 기존 ERP 또는 다른 시스템 연동이 필요합니까?

### 데이터·보안·운영

24. 현재 자료 형식은 엑셀, PDF, 이메일 또는 시스템 중 무엇입니까?
25. 업체명, 대표자명, 연락처 등 민감한 개인·기업 정보를 가명(예: OO농산, 홍길동)이나 마스킹(별표·OO) 처리한 샘플 엑셀 데이터를 몇 건(10~20건 내외) 제공해 주실 수 있습니까?
26. 계약서·인증서 원본 저장이 가능합니까?
27. 개인정보 또는 영업기밀 항목은 무엇입니까?
28. 외부 클라우드, 학교 서버 또는 개발장비 사용 제한이 있습니까?
29. 예상 사용자 수와 역할별 권한 구분이 필요합니까?
30. 최종 결과물은 시연용 PoC입니까, 실제 반복 사용 가능한 MVP입니까?
31. PoC 성공을 판단할 필수 시나리오와 기준은 무엇입니까?
32. PoC 종료 후 실제 서비스 전환 계획이 있습니까?
