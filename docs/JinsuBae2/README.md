# JinsuBae2 기획 문서

- 작성자: JinsuBae2
- 최종 수정일: 2026-09-22
- 상태: 초안

한국농산과의 첫 미팅 전 작성한 개인 기획 자료다. 실제 업무 절차와 데이터가 확인되지 않은 상태이므로 모든 설계는 검증 가능한 가설로 관리한다.

## 문서 목록

| `agenda.md` | 첫 미팅 진행안 |

| `system-design.md` | 정보 없이 정의 가능한 논리 시스템 구조 |

## 사용 원칙

- 기업 확인 전까지 문서 상태는 `초안`으로 유지한다.
- 미팅 답변으로 검증된 내용은 근거와 확인일을 기록한다.
- 가설이 틀리면 기존 기록을 삭제하지 않고 변경 이유를 남긴다.
- 실제 계약서, 인증서, 개인정보와 영업기밀은 저장하지 않는다.
