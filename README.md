# 한국농산 협력업체 통합관리 PoC

한국농산의 협력업체, 계약, 인증, 발주 및 납기 자료를 통합 관리하고 계약 및 인증 만료 알림 기능을 검증하기 위한 캡스톤 디자인 프로젝트입니다.

## 현재 단계

- 기업 미팅 전 요구사항 및 문제 정의
- 팀원별 기획안 작성
- PoC 범위와 우선순위 합의

## 문서 작성

팀원별 기획서는 `docs/plans/<GitHub-ID>/` 폴더에 작성합니다. 상세한 파일명과 작성 규칙은 [docs/README.md](docs/README.md)를 확인하세요.

## 예정 범위

- 협력업체 기본정보 통합관리
- 계약 및 인증 자료 관리
- 계약 및 인증 만료 예정 알림
- 발주 및 납기 현황 조회
- 관리자 대시보드
